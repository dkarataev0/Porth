# Даниил Каратаев — сайт-портфолио

Живой анимированный сайт: интро-шоу с голосом, затем сайт на скролле (hero, услуги, кейсы, процесс, контакты).
Vite + React + TypeScript, GSAP (ScrollTrigger, SplitText, Flip, MotionPath, DrawSVG), Lenis.

```bash
npm install
npm run dev        # разработка
npm run build      # продакшен-сборка в dist/
npm run preview    # посмотреть сборку на http://127.0.0.1:4173
```

## Что поменять под себя

| Что | Где |
| --- | --- |
| Telegram, WhatsApp, e-mail, адрес формы | `src/config.ts` |
| Навыки, проекты и тексты кейсов, шаги процесса | `src/data.ts` |
| Скриншоты проектов (длинные, ~720 px шириной, `.webp`) | `public/work/` |
| Домен для `og:image` и canonical | `.env` → `VITE_SITE_URL` |
| OG-картинка 1200×630 | `public/og.png` |

Форма заявки: если в `FORM_ENDPOINT` пусто, она открывает письмо в почтовой программе; если указать адрес (Formspree и т.п.), отправляет JSON методом POST.

## Озвучка

Голос сцен берётся так:

1. **Готовые mp3.** Сейчас в `public/voice/` лежит озвучка, сгенерированная через ElevenLabs. Готовые файлы работают в любом браузере. Чтобы перегенерировать: файлы `public/voice/scene1–4.mp3` + `manifest.json`. Создаются командой
   ```bash
   ELEVENLABS_API_KEY=... npm run voice
   # голос по желанию: ELEVENLABS_VOICE_ID=...
   ```
   Модель `eleven_multilingual_v2`, русский текст. Тексты в `scripts/generate-voice.mjs` должны совпадать с `*_TEXT` в `src/intro/*.tsx`: если меняете реплику, меняйте её в обоих местах и запускайте команду заново.
2. **Запасной вариант.** Если файлов нет, звучит голос браузера (Web Speech API, `ru-RU`).
3. **«Без звука».** Сцены идут по номинальной длительности, реплики показываются субтитрами.

Каждая сцена живёт ровно столько, сколько звучит её реплика: таймлайн GSAP строится по длительности аудио. Фоновая музыка (~15%) и whoosh-эффекты синтезируются в браузере (Web Audio), отдельных файлов не нужно. Кнопка mute всегда видна.

## Поведение

- Первый визит: стартовый экран (клик нужен, чтобы браузер разрешил звук) → 4 сцены → сайт. Кнопка «Пропустить» и клавиша Esc работают в любой момент.
- Повторный визит: интро не показывается (флаг в `localStorage`, ключ `porth.intro.seen.v1`). В подвале есть «Посмотреть интро снова».
- `prefers-reduced-motion`: без интро, без плавного скролла и pin-сцен, анимации мягкие.
- Телефон: интро упрощено (меньше частиц, карточки навыков в колонку), без тяжёлого 3D.

## Структура

```
src/
  audio/sound.ts      озвучка (mp3 → Web Speech), эмбиент, whoosh, mute
  intro/              стартовый экран, 4 сцены, частицы, привязка таймлайна к голосу
  site/               шапка, hero, услуги (pin+scrub), портфолио + кейс (Flip), процесс, контакты
  components/         иконки навыков, превью-скролл, магнитные кнопки, курсор
  lib/                GSAP-плагины, Lenis
scripts/generate-voice.mjs
```
